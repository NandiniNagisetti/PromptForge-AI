# PromptForge AI
### Intelligent Prompt Engineering and LLM Evaluation Platform

PromptForge AI is a full-stack AI platform designed to experiment with prompt engineering strategies and evaluate how different prompts influence Large Language Model (LLM) responses.

## Key Features

- Interactive React-based dashboard
- Multiple prompt engineering strategies
- LLM response generation using Ollama
- Qwen2.5 model integration
- Prompt sensitivity analysis
- Response comparison and similarity evaluation
- Python-based AI service integration

## Technology Stack

- **Frontend:** React.js, TypeScript, Vite
- **Backend:** Node.js, Express.js
- **AI Service:** Python, FastAPI
- **LLM:** Ollama, Qwen2.5:3b

## Project Structure

- `frontend/` – React dashboard
- `backend/` – Node.js and Express backend
- `ai_service/` – Python AI service

## Project Objective

To study how prompt variations affect LLM-generated responses and evaluate their consistency, similarity and performance.
